# 仕様書：DailyRecordPage (日次記録画面)

## 1. 目的

特定の植物、特定の日の栽培データ（環境データ、センサーデータ、アドバイス）を一覧表示する。

## 2. 画面構成要素

本画面は以下の主要コンポーネントで構成される。

### A. ヘッダー・日付選択エリア (DateSelector)

- 戻るボタン（プランター選択画面へ）
- 日付選択ツール (`DatePicker`)
- 閲覧時点の時刻表示（選択日の日付 + 30分単位に丸めた時刻。過去日を選んだ場合も日付部分は選択日を表示する）

### B. 環境データサマリー (EnvironmentSummary)

- 土壌温度、土壌水分量、室内温湿度、日射量の最新または指定時刻値の表示
- EC値（当日データのみ表示）
- CO2濃度（当日最新または指定日の最終データ）

### C. 栽培アドバイス (AdviceSection)

- 栽培開始からの経過日数に基づくアドバイスメッセージの表示

### D. グラフエリア (DailyCharts)

- 指定日の各センサーデータの推移グラフ
- 標準表示と加工表示（最大・最小・平均等）の切り替え機能

## 3. データ取得ロジック (useDailyEnvironment)

以下のデータを Supabase から取得し、管理する。

| データ種別      | 取得タイミング | 備考                                 |
| :-------------- | :------------- | :----------------------------------- |
| PlantInfo       | 初期化時       | `plantName` から `plantId` を取得    |
| EnvironmentData | 日付変更時     | 指定日の基本環境情報                 |
| SensorData      | 日付変更時     | 土壌温度、水分量、室内温湿度、日射量 |
| EC Data         | 日付変更時     | 指定日のEC値                         |
| CO2 Data        | 日付変更時     | 指定日のCO2濃度                      |

## 4. テスト項目・期待される動作

- [ ] 日付を変更すると、すべてのグラフとサマリー値がその日のデータに更新されること。
- [ ] データが存在しない場合、適切なエラーメッセージ（「データがありません」等）が表示されること。
- [ ] 栽培開始日より前の日付を選択した場合、アドバイス欄に警告が表示されること。
- [ ] グラフの「標準/加工」切り替えが正常に動作すること。
