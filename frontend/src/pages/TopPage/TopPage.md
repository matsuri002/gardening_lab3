# 仕様書：TopPage

## 1. 役割・目的

栽培中の野菜の種類（コマツナ、トマト等）を選択するための画面。
アプリケーションのエントリーポイント（ルートパス `/`）に位置し、データベース（またはモックデータ）から栽培中の野菜の種類一覧を取得してボタンとして表示する。
本ファイルはコンポーネントとロジックを統合する「コンテナ」としての役割のみを持つ。

## 2. 構成

### 2.1 データ取得・状態管理（Hooks）

- **`usePlantTypes`**:
  - 責務：Supabaseの `plants` テーブルから登録されている野菜の種類（`plant_type`）のユニークなリストを取得する。モック切り替えフラグ（`VITE_USE_MOCK`）の制御もこの中でカプセル化する。

### 2.2 UI コンポーネント

- Material-UI（MUI）の `Button` や `Container` を使用して、取得した野菜の種類の選択肢を並べる。
- ボタン押下時に、選択した野菜の種類に応じた鉢（プランター）選択画面（`/select-planter/:plantType`）へ画面遷移（`useNavigate`）する。

## 3. データフロー

1. `TopPage` が `usePlantTypes` を呼び出し、野菜の種類一覧（`plantTypes`）を受け取る。
2. `plantTypes` をループしてボタンを描画し、クリック時に `navigate` を実行する。
