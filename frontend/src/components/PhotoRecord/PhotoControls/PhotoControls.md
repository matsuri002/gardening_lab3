# 仕様書：PhotoControls

## 1. 役割・目的

ユーザーが写真の遷移（前へ、次へ）やスライドショーの再生・停止を操作するためのコントロールパネル UI。

## 2. Props

- `currentIndex`: 現在表示されている写真のインデックス（0始まり）。
- `totalPhotos`: 写真の総枚数。インデックス表示およびボタンの非活性化判定に使用する。
- `isPlaying`: スライドショーが再生中かどうか。
- `loading`: データのローディング状態。
- `onPrev`: 前の写真へ戻る関数。
- `onNext`: 次の写真へ進む関数。
- `onPlay`: スライドショーを再生する関数。
- `onStop`: スライドショーを停止する関数。
