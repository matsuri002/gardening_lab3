# 仕様書：AdviceSection (アドバイスセクション)

## 1. 目的
栽培開始からの経過日数に基づき、現在の生育状況に応じたアドバイスを表示する。

## 2. インターフェース (Props)

### Props
- `adviceText`: `string | null`
- `daysFromStart`: `number` (経過日数)

## 3. 表示仕様
- カード形式で表示し、上部に「経過日数：X日目」というラベルを表示する。
- `adviceText` が存在する場合、その内容を読みやすいフォントサイズで表示する。
- 特徴的なアイコン（例：Avatar付きの電球アイコン等）を添えて、アドバイスであることを強調する。
- 経過日数が負（栽培開始前）の場合は、その旨を表示する。

## 4. テスト項目
- [ ] 経過日数に応じた正しいアドバイスが表示されること。
- [ ] アドバイスが `null` の場合、不自然な空白ができないよう配慮されていること。
