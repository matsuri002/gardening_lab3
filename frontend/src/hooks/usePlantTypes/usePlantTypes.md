# 仕様書：usePlantTypes フック

## 1. 役割・目的

栽培中の野菜の種類（`plant_type`）のユニークなリストを取得するカスタムフック。
Supabase から `plants` テーブルのデータを取得して重複を排除する処理、およびモックデータへの切り替え処理をカプセル化する。

## 2. API設計

### 2.1 Hooks の入出力

- **入力（引数）**: なし
- **出力（返り値）**:
  - `plantTypes` (`string[]`): 取得した野菜の種類のユニークなリスト。
  - `loading` (`boolean`): データの取得状態を表すフラグ。
  - `error` (`Error | null`): エラーが発生した場合のエラーオブジェクト。

## 3. 実装詳細

- **モックモード（`VITE_USE_MOCK === "true"`）**:
  - `["コマツナ", "トマト"]` を即座に設定し、データロードを完了する。
- **本番モード**:
  - Supabase の `plants` テーブルから `plant_type` カラムを全取得。
  - 取得した配列から `Set` を用いて重複を排除したユニークなリストを作成し、`plantTypes` に設定する。
