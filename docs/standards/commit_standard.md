# コミット規約 (Commit Standard)

このプロジェクトでは、コミットメッセージの視認性と分類を容易にするため、`gitmoji` の使用を義務付けます。

## 1. 基本ルール

- **gitmoji 必須**: すべてのコミットメッセージの先頭には、必ず規約で定められた絵文字（gitmoji）を含める必要があります。
- **プッシュ制限**: 絵文字が含まれていないコミットは、原則としてプッシュを禁止します（セルフチェックまたは CI での確認を推奨）。
- **言語**: コミットメッセージの本文は**日本語**を基本とします。簡潔かつ明瞭に作業内容を記述してください。

## 2. 主要 gitmoji 対応表

| 絵文字 | コード               | 用途                                                    |
| :----- | :------------------- | :------------------------------------------------------ |
| ✨     | `:sparkles:`         | 新機能の追加 (New features)                             |
| ♻️     | `:recycle:`          | コードのリファクタリング (Refactoring)                  |
| 🎨     | `:art:`              | コードスタイル/フォーマットの修正 (Formatting)          |
| 🔧     | `:wrench:`           | 設定ファイルの変更/環境整備 (Configuration/Environment) |
| 📝     | `:memo:`             | ドキュメントの作成/更新 (Documentation)                 |
| 🐛     | `:bug:`              | バグ修正 (Bug fixes)                                    |
| ✅     | `:white_check_mark:` | テストの追加/修正 (Testing)                             |
| 🚚     | `:truck:`            | ファイルの移動/名前変更 (Moving/Renaming)               |

## 3. メッセージ形式

`[gitmoji] [タイプ]/[番号]: [作業内容の要約]`
例: `✨ feat/4: setup development standards`
